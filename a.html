说明

安装流程分 4 步，可单独安装 / 重装 / 更新：
① Linux 环境：proot + Ubuntu rootfs（约 30MB）
② 基础工具：apt 换国内源 + curl/git/python3/make/xz
③ Node.js：v24.19.0（含 pnpm / node-gyp 附加工具）
④ deepseek-harness：预构建包 或 直连 GitHub 源码构建

每个下载源都有多个镜像，自动测速选最快；只更新 deepseek-harness 就单独点第 ⑤ 步。
