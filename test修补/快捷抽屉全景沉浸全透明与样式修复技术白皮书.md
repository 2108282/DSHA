# DSHA 快捷抽屉全景沉浸透明与样式重构

> **归档分支**：`test`  
> **涉及核心组件**：`QuickChatSheetActivity.java`、`SettingsFragment.java`、`themes.xml`  
> **文档位置**：`test修补/快捷抽屉全景沉浸全透明与样式修复技术白皮书.md`

---

## 一、概述与架构背景

在 DSHA 移动端容器环境中，快捷抽屉（`QuickChatSheetActivity`）为用户提供了无需切出当前应用即可随时唤起 DSH 官方 Web 界面的核心悬浮入口。

为实现极致的移动端视觉体验，用户开启【快捷抽屉沉浸全透明】开关后，抽屉底板应呈现通透毛玻璃质感，透出手机桌面壁纸或宿主应用。然而，DSH 官方前端作为桌面级 Web 设计，默认带有大量不透明的背景图层与实心布局，直接全透会导致：
1. **白天模式视口纯白**：官方在白天强制写入 `#ffffff` 导致抽屉中间出现巨大白色遮挡块；
2. **任务横幅不透明**：任务进度横幅吃专用颜色变量，呈现为突兀的实心黑/灰条；
3. **文字穿透与输入框底座死色冲突**：若粗暴将输入框底座透明，长对话向上滚动时会从输入框背后穿透重叠；若强行填入实心色，输入框下方又会出现死黑/死白大补丁，违背全透明初衷；
4. **状态栏空行与深色失效**：Activity 继承架构与系统 WindowInsets 冲突导致顶部多出一道空白行，且基类变更可能切断与 `AppCompatDelegate` 的夜间模式联动。

本文档详细记录上述问题的底层机制、涉及的前后端各模块代码、修改内容与最终实现的完整逻辑。

## 二、各个代码模块与图层功能索引

| 层级 | 代码文件 / 类 / 变量 | 具体功能与承担角色 |
| :--- | :--- | :--- |
| **Android 窗口** | `Theme.DeepseekHarness.SheetTransparent` (`themes.xml`) | 抽屉专用的无 ActionBar 全屏透明窗口样式，声明 `android:windowIsTranslucent=true` 与 `android:windowBackground=@android:color/transparent`。 |

| **前端全局变量** | `--dsw-specific-input-major` (`dsh-client-ui-theme`) | 输入框卡片自身的主填充色变量。 |
| **前端全局变量** | `--dsw-alias-markdown-code-block` 系列 | Markdown 代码块与行内代码背景色变量。 |
| **前端 DOM 容器** | `.wSkVaW_root` / `.wSkVaW_scrollBody` / `.wSkVaW_viewArea` | DSH 会话滚动视口主体容器，装载全部历史消息流。 |
| **前端 DOM 容器** | `.wSkVaW_composerSeat` (`data-composer-seat`) | 输入框底座容器，官方使用 `position: sticky; bottom: 0` 承载输入框与底部状态栏。 |

## 三、修改详情与实现逻辑对照

### 1. 抽屉黑夜模式联动与顶部状态栏空白行根除

* **修改文件**：
  - `app/src/main/res/values/themes.xml`
  - `app/src/main/res/values-night/themes.xml`
  - `app/src/main/java/com/deepseekharness/app/ui/QuickChatSheetActivity.java`
* **修改前的问题**：
  - 之前为避让状态栏，错误将 `QuickChatSheetActivity` 改为继承 `ComponentActivity`，脱离了 `AppCompatDelegate` 管辖，导致夜间模式下抽屉变成了浅白蓝色；
  - 若直接使用 `AppCompatActivity`，系统沉浸式框架默认将状态栏高度作为 Padding 塞入 DecorView，导致“DSHA 对话”上方挤出一条多余的空白行。
* **修改后的代码**：
  ```java
  // 1. 坚决恢复继承 AppCompatActivity，保证 AppCompatDelegate 夜间广播 100% 触达
  public class QuickChatSheetActivity extends AppCompatActivity {
  
      @Override
      protected void onCreate(Bundle savedInstanceState) {
          super.onCreate(savedInstanceState);
  
          Window window = getWindow();
          if (window != null) {
              // 2. 显式关闭系统沉浸式安全边距注入
              WindowCompat.setDecorFitsSystemWindows(window, false);
              if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.P) {
                  WindowManager.LayoutParams lp = window.getAttributes();
                  lp.layoutInDisplayCutoutMode = WindowManager.LayoutParams.LAYOUT_IN_DISPLAY_CUTOUT_MODE_SHORT_EDGES;
                  window.setAttributes(lp);
              }
              window.setBackgroundDrawable(new ColorDrawable(Color.TRANSPARENT));
              window.addFlags(WindowManager.LayoutParams.FLAG_DIM_BEHIND);
              window.setDimAmount(0.42f);
              window.setLayout(WindowManager.LayoutParams.MATCH_PARENT, WindowManager.LayoutParams.MATCH_PARENT);
              window.setSoftInputMode(WindowManager.LayoutParams.SOFT_INPUT_ADJUST_NOTHING);
              if (window.getDecorView() != null) {
                  window.getDecorView().setFitsSystemWindows(false);
                  window.getDecorView().setPadding(0, 0, 0, 0);
                  window.getDecorView().setBackgroundColor(Color.TRANSPARENT);
                  // 3. 消费 Insets 并强锁 padding 归零
                  ViewCompat.setOnApplyWindowInsetsListener(window.getDecorView(), (v, insets) -> {
                      v.setPadding(0, 0, 0, 0);
                      return WindowInsetsCompat.CONSUMED;
                  });
              }
          }
          ...
          // 4. 对 content、rootOverlay、sheetCard 全链路消费 Insets
          View content = findViewById(android.R.id.content);
          if (content != null) {
              content.setFitsSystemWindows(false);
              content.setBackgroundColor(Color.TRANSPARENT);
              content.setPadding(0, 0, 0, 0);
              ViewCompat.setOnApplyWindowInsetsListener(content, (v, insets) -> {
                  v.setPadding(0, 0, 0, 0);
                  return WindowInsetsCompat.CONSUMED;
              });
          }
      }
  ```
* **实现效果**：
  - 黑夜模式下，抽屉底色恢复为规范的 `#10141B`（深蓝黑微透光），白天模式恢复为 `#EBF5F8FC`（浅白蓝微透光）；
  - 顶栏 4 个功能按钮（关闭、终端控制台、新建会话、全屏展开）与“DSHA 对话”标题紧紧贴紧卡片顶端圆角，多余的空白行被彻底消灭。

  - 任务进度横幅卡片使用了 `--dsw-specific-tip`，未随透明开关改变，始终呈现死灰或死黑色。
* **修改后的代码**：

### 3. 输入框底座全透明 + 会话二段物理裁切（文字到输入框自动消失）

* **修改文件**：`QuickChatSheetActivity.java`（`refreshImmersiveTheme` 方法）
* **核心业务逻辑**：
  - **绝不使用实心色挡板**：若使用实心色垫底，输入框及其下方会被涂上一块死黑/死白大补丁，破坏全景全透明；
  - **文字必须在输入框上方切除消失**：长对话向上滚动时，文字到达输入框上边缘必须立刻消失不可见，绝对不能漏到输入框背后和下面与输入文字产生双重重影。
* **修改后的代码**：
  ```css
  /* 1. 消息滚动视口：物理截断在输入框上方，超出下边界的文字直接被 overflow 物理切断瞬间消失 */
  div[class*='_scrollBody'] {
    margin-bottom: var(--dsh-composer-height, 148px) !important;
    overflow-y: auto !important;
    overflow-x: hidden !important;
  }
  
  /* 2. 输入框底座：完全透明透光，固定绝对定位贴底，绝不使用实心色补丁 */
  div[class*='_composerSeat'] {
    position: absolute !important;
    bottom: 0 !important;
    left: 0 !important;
    right: 0 !important;
    z-index: 10 !important;
    background: transparent !important;
    background-color: transparent !important;
    background-image: none !important;
  }
  
  /* 3. 输入框卡片：半透明通透微光衬底，位置端正 */
  div[class*='uV2eYG_card'] {
    background: var(--dsw-specific-input-major) !important;
    background-color: var(--dsw-specific-input-major) !important;
    border: 1px solid rgba(128, 128, 128, 0.15) !important;
  }
  ```
* **实现效果与物理机制**：
  1. 利用 DSH 官方自带的 `ResizeObserver` 动态计算变量 `--dsh-composer-height`，滚动视口 `_scrollBody` 的下边缘永远紧密贴合在输入框上方；
  2. 当用户向上滑动长对话时，文字滚动到输入框上方的一瞬间，直接被 `_scrollBody` 的 `overflow: auto/hidden` **物理切断（Clip）**，当场消失，无法越过边界；
  3. 输入框卡片保持微透光卡片质感，输入框下方（状态行及留白区）**完全透明**，桌面壁纸和应用界面清晰透出，两全其美！

### 4. 输入法呼出时的自适应联动机制

当用户点击输入框唤起第三方软键盘时：
1. **Android 原生层**：
   - 卡片底部拥有 `keyboardSpacer` 动态占位块；
   - 键盘弹出时，系统监听到键盘高度（例如 `800px`），`keyboardSpacer` 瞬间等额变高为 `800px`；
   - 抽屉整体卡片顶边绝对锁死不被系统向上顶飞，内部 WebView 物理高度等额向上收缩；
2. **Web 前端内部**：
   - WebView 高度收缩后，`_composerSeat` 依靠 `position: absolute; bottom: 0;` 紧贴收缩后的底部，**自然平滑地上浮并端正停靠在键盘正上方**；
   - 滚动视口 `_scrollBody` 同步收缩，其下边缘依然牢牢锁定在抬高后的输入框正上方；
   - 向上滚动的文字依然在输入框顶边被切断消失，无论键盘弹出或收起，均端正严密，绝不穿帮。

### 5. 开关控制与零污染恢复

* **设置页联动**：在 `SettingsFragment.java` 中点击【快捷抽屉沉浸全透明】开关时，通过 `QuickChatSheetActivity.refreshImmersiveTheme(Context)` 实时向单例 WebView 分发注入；
* **关闭时完全复原**：
  ```javascript
  if (!immersive) {
    if (style) style.remove();
    if (document.documentElement) document.documentElement.style.backgroundColor = '';
    if (document.body) document.body.style.backgroundColor = '';
  }
  ```
  关闭全透明时，动态 `<style>` 被直接从 DOM 树完全移除，页面内联背景清空，100% 恢复 DSH 官方原本的实心原生样式，零代码残留。
