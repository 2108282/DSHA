# v1.2.0-rc1.3 更新说明

本版由贡献者 [@ym2025szz](https://github.com/ym2025szz) 推进，感谢原作者 [@qiannianhuanxiang](https://github.com/qiannianhuanxiang) 及其他贡献者。

## 更新与下载

- 设置中的检查更新支持稳定版与预览版通道，预览安装包默认选择预览通道。
- 使用明确的版本码匹配 standard / low、最低系统与 arm64 架构，防止降级或混装。
- 展示更新说明与下载进度，支持取消、重试；下载完成后核验大小、SHA-256、包名、版本及签名，再交给 Android 安装器。
- 网站下载信息、App 更新接口和 GitHub 发布正文由最终 APK 的实际元数据统一生成。以后发布预览版时保留上一稳定版的更新入口。

## 从网站安装插件

- [dsha.cc](https://dsha.cc/) 的社区插件详情可以打开 App；也可在[链接安装页](https://dsha.cc/install/)输入 HTTPS 链接或 npm 包名。
- App 先下载和解析实际插件包，展示名称、作者、版本、兼容范围及摘要，再由用户确认安装。未声明的作者或兼容范围明确显示为未知。
- 安装完成后提示重启 Web。未安装 App 时可从网页下载 APK；首次初始化完成后可继续安装确认。
- 内置插件入口打开管理页；不会把网站浏览记录当成手机安装状态。
- 目录加入两款已核对并作有限真机验证的社区插件：会话健康检查与子代理模型选择。详情页包含真实截图与验证范围。

## 诊断、更新与恢复

- 诊断报告包含应用版本、系统与机型、内核、浏览引擎、环境检查和最近失败步骤，可复制或导出。
- 报告不读取对话、API 配置、终端命令或完整系统日志；对事件和手工复现描述进行凭据脱敏，不自动上传。
- 提供证书/npm/pnpm/Python 修复，文件选择失败时给出备用选择器入口指引。
- 插件管理显示已装及可更新版本，更新前先确认包信息；失败保留现有插件，每个插件只保留唯一上一版，可回退。
- 安全启动暂时禁用第三方插件。恢复时还原之前启用状态，同时尊重用户在安全模式期间作出的手工禁用。
- 修复导入插件对 dsh 自带依赖模块的解析路径，避免部分插件安装后因找不到依赖而无法启动。

作者投稿流程、插件开发模板沿用原有内容，本轮不扩展。

## 交付文件

| 文件 | 最低系统 | 大小 |
|---|---|---:|
| `dsha-1.2.0-rc1.3.apk` | Android 11 / API 30 | 212.45 MiB |
| `dsha-1.2.0-rc1.3low.apk` | Android 6 / API 23 | 289.49 MiB |

两版仅支持 arm64，共用 `com.dsh.client`，版本码均为 **112**，沿用历史发布签名。文件及各自 `.apk.sha256` 位于源码工作区 `release`，也可从[官网下载](https://dsha.cc/download/)。[GitHub 发布页](https://github.com/DSH-APP/DSHA/releases/tag/v1.2.0-rc1.3)标记为 **Pre-release**，由贡献者账号发布。

包内 dsh 仍为 `0.1.2-rc.1`，环境版本仍为 **9**，覆盖同签名旧版保留已有环境。两版共享应用数据，不能并排安装。

实际测试及限制见[本次验收记录](../release-rc1.3-2026-09-07.md)。Android 6—12、Android 17 和 16 KB 页设备尚需补充真机覆盖；最低系统配置不等于这些设备都已实测。
