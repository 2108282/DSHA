更新与恢复功能预览版，由贡献者 @ym2025szz 推进，感谢原作者 @qiannianhuanxiang 及其他贡献者。

• 更新：稳定 / 预览通道，自动匹配高低安卓版本；显示发布说明和下载进度，支持取消、重试，核验摘要、包名、版本和签名后交给系统安装。
• 网页安装：从 dsha.cc 唤起 DSHA，查看插件实际名称、作者、版本和兼容范围，确认后安装，完成后提示重启 Web。
• 诊断：收集应用、Android、内核、运行环境和失败步骤，可复制或导出脱敏报告；提供证书与 npm 修复及文件选择故障指引。
• 插件恢复：检查可更新版本；失败时保留原插件，更新后可退回唯一上一版。安全启动暂时禁用第三方插件，支持恢复此前启用状态。
• 插件兼容：链接入口支持 npm 包名；补齐导入插件对 dsh 自带模块的解析路径，修复部分社区插件安装后无法启动的问题。

标准版面向 Android 11+，兼容版最低 Android 6，均仅支持 arm64。包内 dsh 仍为 0.1.2-rc.1，环境版本保持 9，同签名覆盖安装保留已有环境。实际设备验证范围见源码中的本次验收记录。
